# 籠城ビルダー

タワーディフェンス＋建築ゲームのプロトタイプ。左右から途切れず押し寄せるゾンビを武器とバリケードで防ぎ、倒した報酬で上の階を建てて「何階まで建てられたか」を競います。

`index.html` をブラウザで開くだけで遊べます（依存ライブラリなし）。

## 主な仕様（v0.5）

- 昼35秒・夜40秒のサイクル。夜ごとに月が三日月 → 半月 → 赤い満月と満ち、満月の夜にボスゾンビが出現
- 脅威レベル（約45秒ごとに上昇）でゾンビの出現量・体力がゆるやかに増加
- 各階の左右に武器スロット（ハンドガン → ライフル → マシンガン → キャノン）。射程距離と下向き射角で命中判定
- バリケード：木の柵 → 石の壁 → 鉄の壁（無敵）＋高さ4段階。ゾンビは積み重なって乗り越える
- 5階到達で空の敵（コウモリ・カラス・ハゲワシ・爆弾ガラス）
- 屋上スナイパー（3階から）、時限爆弾／大型爆弾
- 修理費はダメージに比例
- バランス調整用スライダー（射程・下向き射角・出現量）
